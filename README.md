# Tidy Craft: Inventory Tetris

A standalone mobile-first cozy puzzle web game.

## Run locally
Open `index.html` in a modern browser. For best PWA behavior, serve the folder from a static HTTP server.

Example:
`python3 -m http.server 8000`

Then visit `http://localhost:8000`.

## Deploy
The folder can be deployed to any static host such as GitHub Pages, Netlify, Cloudflare Pages, or similar.

## Notes
- Progress is saved with localStorage.
- No backend is required.
- Touch and mouse input are supported.
- The game is designed for portrait mobile play.
